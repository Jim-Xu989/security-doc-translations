# 公开安全资料 · 中文翻译集

> 非官方中文译本合集。本仓库用于持续收录**可公开发布**的英文安全 / 技术标准的个人中文翻译。

## 仓库定位
- **收录对象**：OWASP、NIST、MITRE、CSA 等公开安全 / 技术标准的**非官方**中文翻译。
- **目标读者**：中文安全从业者、开发者与研究人员。
- **性质说明**：纯个人翻译整理，**不代表任何官方立场**；如译文与英文原文存在差异，一律以英文原文为准。

## 许可
- 译文采用 **CC BY-SA 4.0**（知识共享署名-相同方式共享 4.0 国际许可），与多数原始文档许可一致。
- 使用本仓库内容请保留署名，并以相同方式共享。
- 各原始文档的版权归其原作者 / 组织所有。

## 目录约定
按**来源（发布方）**分子目录，便于归类与未来扩展：
- `owasp/` —— OWASP 系列（如 Top 10 for LLM Applications、ASVS 等）
- `nist/` —— NIST 系列（规划中）
- `mitre/` —— MITRE 系列（规划中）
- `csa/` —— CSA 等其他来源（规划中）

每篇译文建议包含：原文标题与版本、原文链接、许可声明，以及便于回查的原文页码锚点（如 `<!-- 原书第 N 页 -->`）。

## 如何新增译文
1. 在对应来源目录下新建 `<标准名>-中文翻译.md`；
2. 文首注明原文标题、版本、链接与许可；
3. 直接推送（若有权限）或提交 Pull Request。
